## Description

*(Copy-paste the paragraph below. Character count: ~1,250 — within the 1,500-character limit.)*

AIVIA (Alzheimer Intelligent Virtual Interactive Assistant) is a Flutter-based Android application designed as a specialized assistive tool for Alzheimer's patients and their family caregivers. The app addresses real-world challenges faced by individuals with cognitive impairment by delivering a suite of intelligent, accessibility-first features in a single mobile platform.

The application supports two user roles — patients and family members. Patients benefit from a daily activity journal with local reminders, an on-device face recognition feature powered by GhostFaceNet (TFLite) and Google ML Kit to help identify familiar people, and a one-tap emergency alert that instantly notifies caregivers. Family members have access to a real-time dashboard for managing patient activities, a live location tracking map with geofencing alerts, and tools to manage the patient's known-persons database used by the face recognition module.

The backend is built on Supabase (PostgreSQL) with Row Level Security, pgvector for face-embedding similarity search, and PostGIS for geospatial queries. Push notifications are delivered via Firebase Cloud Messaging through Supabase Edge Functions. State management is handled with Riverpod. The UI follows WCAG AAA accessibility standards — featuring a therapeutic color palette, Poppins font at minimum 18 sp, full dark mode, and 48 dp minimum touch targets — all optimized for users with cognitive impairment.
